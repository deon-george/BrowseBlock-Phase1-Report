\addcontentsline{toc}{chapter}{\numberline{}Abstract}
\begin{center}
  \vspace*{1cm}
  \textbf{\large Abstract}
\end{center}
BrowseBlock is an AI/ML-powered browser security platform designed to detect and help prevent browser-based attacks in real time. A Manifest V3 Chromium extension monitors supported navigation, webpage scripts, redirects, frames, notifications, downloads, email content, and observable extension activity. A React dashboard supports authenticated manual scans of URLs, QR codes, emails, and files, together with threat reports, explanations, and analytics. The FastAPI backend validates requests and coordinates XGBoost URL analysis, Random Forest email screening, static security rules, QR decoding, file inspection, and RAG/LLM-assisted email analysis. Firebase Authentication manages dashboard identity, while the backend remains the controlled boundary for protected operations; the finalized design does not require a separate application database. The proposed system covers URL and fake-QR phishing, cross-site scripting, credential harvesting, malicious redirects, clickjacking, cryptojacking, malicious downloads, email phishing, notification scams, and browser-extension abuse. Each result is classified as Safe, Suspicious, or High-risk and includes evidence, analysis completeness, and the actual protective action. The Phase I work establishes the requirements, architecture, methodology, literature foundation, and evaluation plan for a privacy-conscious security layer that complements existing browser and antivirus protections.
